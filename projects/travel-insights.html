Travel Insights

Four Italian travel operators, four different website structures, one messy question: what is the market actually selling? This project scrapes the catalogues, normalises destinations and trip metadata, and turns the result into an interactive dashboard — 2,051 packages, 117 resolved countries, zero manual spreadsheets.

The problem

Every catalogue speaks a different dialect.

One operator exposes a clean Country field. Another returns a list of countries and macro-regions. A third stores destinations as marketing collections (“Hai voglia di vibes da isola?”) and puts the real country in the subtitle. The itineraries arrive as JSON strings, nested dicts or plain prose.

The pipeline treats the catalogues as raw inputs: it normalises country names and aliases, maps destinations to continents, extracts trip length and content depth, and tags each package with a small set of travel vibes. Everything ships as one JSON payload consumed by the dashboard.

Result: 94.4% of packages resolve to a country, with a documented fallback for the remaining 5.6% instead of silently dropping them.
Pipeline

Scrape

Selenium and requests/trafilatura collectors for WeRoad, SiVola, ViaggiAvventure and FourSeasons.

Normalise

Country aliases, macro-regions, lists, marketing labels, currencies and malformed fields.

Enrich

Itinerary length, description depth, structured-itinerary coverage and vibe tags.

Publish

A compact JSON payload rendered with Plotly on a static GitHub Pages site.
